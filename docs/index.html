Code Recorder for Eclipse

코드 작성 과정과 파일 변경을 기록하고 JSON 파일로 저장하는 Eclipse 확장 프로그램입니다.

설치

Eclipse의 Help → Install New Software… → Add…에서 다음 주소를 Location에 입력하세요.

https://pinnpublic.github.io/code-recorder-eclipse/updates/

Code Recorder를 선택하고 설치를 진행한 뒤 Eclipse를 재시작합니다.

배포 버전: 0.3.5. 대상 환경: Eclipse IDE 2026-09 (4.41.0), Windows, IDE 실행용 Java 25.

녹화

코드 녹화 → 녹화 창 열기에서 대상 프로젝트나 폴더를 선택하고 녹화 시작을 누릅니다. 녹화를 마치면 종료 / 내보내기를 눌러 .coderec.json 파일을 저장합니다.
